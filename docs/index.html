ลองเอง (แท็บ "ลองเอง ▶")
  1. กดปุ่ม scenario ด้านบน editor หรือพิมพ์แก้ YAML เอง — เช่นลบบรรทัด phone
  2. ดูฝั่ง oasdiff: PR ถูกบล็อกไหม
  3. ดูฝั่ง ของเรา: แอปไหนเป็นสีแดง (พัง) สีส้ม (ต้องย้าย) สีเทา (ไม่โดน)
  4. ติ๊ก checkbox ว่าแอปอ่าน field ไหน — เช่นให้ App C อ่าน phone ด้วย แล้วดูว่าผลเปลี่ยน

กำลังโหลด…

oasdiff ทำได้

  • เทียบ spec สองเวอร์ชัน มีกฎหลายร้อยข้อ (784 รายการใน v1.40.0)
  • บล็อก PR เมื่อลบโดยไม่ deprecate หรือเปลี่ยน type (exit code ใน CI)
  • รู้จัก deprecated + x-sunset
  • ออก JSON ให้โปรแกรมเราอ่านต่อ · license Apache-2.0

oasdiff ทำไม่ได้ → โปรเจกต์ของเรา

  • ไม่รู้ว่าแอปไหนอ่าน field ไหน → ลบ optional field ผ่านได้ทั้งที่มีแอปพัง
  • ไม่แจ้งเฉพาะทีมที่โดน → เราส่ง notice พร้อมวัน sunset + field ทดแทน
  • ไม่ติดตามการย้าย → เราเช็กว่าทุกทีมย้ายเสร็จก่อนลบจริง
  • rename = ลบ + เพิ่ม → ใช้ LLM ช่วยเดา rename และเสนอ replacement
